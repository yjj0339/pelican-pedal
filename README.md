# 鹈鹕单车漫游 · Pelican Pedal

一只长嘴鹈鹕蹬着红色小单车，载着车筐里的小鱼，慢慢穿过三种风景。

**在线版（手机可看）：<https://yjj0339.github.io/pelican-pedal/>**

![扫码打开](qr-live.png)

## 它是什么

一个全新的、纯 Canvas 2D 从零手写的骑行动画网页：**单文件、零依赖、零外部资源**，
打开 `index.html` 就能看，也可以直接放到任何静态服务器上。

## 画面里有什么

- **鹈鹕**：大白身、橙黄长喙、会晃的大喉囊，喉囊里还叼着一条会摆尾的小鱼；
  脑袋上有三根随风抖动的冠羽，脖子上围了一条被速度吹得越骑越飘的红围巾。
- **单车**：珊瑚红老式车架、奶油色挡泥板、转动辐条、链条与牙盘，
  车把上有金色车铃，车头挂一个藤编车筐——点一下画面就能听见铃响。
- **两条腿**：真正的两骨骼 IK 求解，脚掌始终踩在踏板上，
  膝盖朝向正确、脚踝随曲柄轻微摆动，不是贴上去的假腿。

## 三种风景

| 场景 | 内容 |
| --- | --- |
| 海滨大道 | 海面、远处小岛、帆船、棕榈树、海鸥、沙滩小花 |
| 金色田野 | 层叠山丘、旋转的风车、农舍、麦浪、木栅栏、向日葵 |
| 清晨城市 | 粉彩楼群、街灯、公交站牌、公园树、热气球、路边护栏 |

每层以不同视差速度滚动（远景 0.05 → 前景 1.36），并跟随骑行速度实时变化。

## 怎么玩

- **速度滑块**：静止 / 慢骑 / 巡航 / 轻快 / 飞驰，速度快了会飘围巾、冒风线。
- **场景按钮**：三处风景即时切换（带一次白闪过渡）。
- **🔔 按铃**：真实合成的铃声（WebAudio），屏幕上还会荡开一圈涟漪。
- **快捷键**：`←` `→` 调速、`空格` 暂停、`B` 按铃，直接点击画面也能按铃。
- **网址参数**：想直接进某个场景可以加参数，例如
  `?scene=field&speed=80`（可选 `seaside` / `field` / `city`，速度 0–100）。

## 本地运行

双击 `index.html` 即可，或者：

```bash
npx serve .
```

## 技术说明

- 全部绘制使用 Canvas 2D，无任何框架、无图片、无字体文件。
- 逻辑分辨率固定 1280×720，按容器等比缩放并适配高分屏（devicePixelRatio ≤ 2）。
- 画面元素的循环铺设由 `tile(offset, period, fn)` 统一处理，
  元素差异用稳定哈希 `rnd(n)` 生成，因此每次刷新景色完全一致。
- 轮速、踏频、身体起伏全部由里程 `dist` 推导：齿比 2.4，轮转角 = 里程 / 轮半径。
